=== QUAN TRỌNG — KHÔNG Dùng File → Open cho file .mermaid ===
.draw.io / diagrams.net chỉ "Open" được file *.drawio hoặc XML (<mxfile...>).
File *.mermaid KHÔNG mở bằng Open — phải dán nội dung qua Insert:

  1. Mở https://app.diagrams.net (hoặc draw.io Desktop)
  2. File → New diagram → chọn Blank
  3. Arrange → Insert → Advanced → Mermaid
     (hoặc Insert → Advanced → Mermaid tùy giao diện)
  4. Copy toàn bộ nội dung file .mermaid → Paste → Insert

Đã có file mở được bằng Open: docs/OTO-domain-diagram.drawio

Cách khác: mở https://mermaid.live → dán code → Export PNG/SVG → kéo ảnh vào diagrams.net.
